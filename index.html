📖 如何使用版本查找指南

如何使用版本查找指南

一、先确定你要做什么

本站提供三种文件，用途完全不同，别下错：

你想做什么需要下载说明
自己玩（单机/进别人服）版本元数据 version.json + 客户端 Client两个都要，导入启动器后自动补全
开服务器（让别人连你）服务端 Server（server.jar）一个就够，不用下客户端
两样都要上面三样全下玩自己的服最常见

只想玩游戏

下载 version.json 和 client.jar 两个文件，按第三章导入 HMCL 或 PCL2 即可开玩。

只想开服务器

下载 server.jar 一个文件即可。放到空文件夹里，命令行运行：

java -Xmx2G -Xms2G -jar server.jar nogui

首次启动会生成 eula.txt，把里面的 eula=false 改成 eula=true，再启动一次才真正开服。

注意：本站提供的是官方原版服务端，不支持插件。要装插件请用 Paper，要装模组请用 Forge/Fabric 服务端。客户端要连自己的服，必须下载相同版本的客户端。

自己开服自己玩

三样都下载：先用 server.jar 开服，再用 version.json + client.jar 导入启动器进游戏，连接 127.0.0.1 即可。

二、怎么下载

  1. 左侧列表选一个版本（正式版建议选最新的，模组推荐 1.20.1）
  2. 右侧「游戏本体」区块会看到两个下载项：
    版本元数据 version.json、客户端 Client（client.jar）
  3. 两个都下载下来，放在同一个文件夹里
  4. 文件名保持默认，不要改

就这两个文件，不用管库文件和资源索引。

三、怎么导入启动器

HMCL

  1. 打开 HMCL，点左侧「版本列表」
  2. 点右上角「安装新游戏版本」
  3. 切到「从本地安装」标签
  4. 选择刚下载的 version.json
  5. HMCL 会自动识别，并联网补全库文件与材质音效
  6. 等待完成，回主页点启动

PCL2

  1. 打开 PCL2，点「下载」→「本地导入」
  2. 选择 version.json
  3. 等待补全完成，回主页启动

官方启动器

不推荐。官方启动器不支持本地导入，需要手动放到 .minecraft/versions/ 目录，步骤繁琐且容易出错。

四、Java 版本必须对应

装错 Java 是启动失败最常见的原因：

游戏版本需要 Java
1.20.5 及以上Java 21
1.17 ~ 1.20.4Java 17
1.16.5 及以下Java 8

HMCL 和 PCL2 都支持在设置里指定 Java 路径，也可以在启动器内直接下载对应 Java。

五、首次导入会发生什么

导入后启动器需要联网补全两样东西：

  • 库文件 libraries：几百个小 jar，约 30-50MB
  • 资源文件 assets：材质、音效、语言包，约 300-500MB

补全是一次性的，完成后可以完全离线游玩。网络慢时耐心等，或换个时间段。

六、要装模组怎么办

版本详情页有「模组加载器」区块，四种可选：

加载器适合场景
Forge老牌模组、大型整合包
NeoForgeForge 分支，1.20.1 之后的新模组
Fabric轻量模组、性能优化类（如 Sodium）
QuiltFabric 分支，模组较少

操作：下拉选版本 → 点下载拿到 installer（安装器）。

  • Forge / NeoForge：双击 installer，选「Install client」，它会自动下载对应版本
  • Fabric / Quilt：本站提供的是服务端 jar，客户端请去官网用 installer

装完模组加载器后，模组文件（.jar）放进 .minecraft/mods/ 目录即可。

注意：加载器版本必须和游戏版本对应。1.20.1 的 Forge 只能装在 1.20.1 上。

七、常见问题

为什么只要下载两个文件？

因为启动器会自动补全库文件和资源文件。本站提供最关键的两样：版本描述和主程序，其余交给启动器联网下载，避免你下几百 MB。

导入后启动器提示版本损坏？

检查两个文件是否在同一文件夹，且文件名没被改过。version.json 必须是启动器识别的那个文件，不能改成别的名字。

启动后黑屏或紫黑方块？

资源文件没补全完。等启动器下载完 assets，或检查网络。

启动报 Java 版本错误？

对照第四节的表格，装对应版本的 Java，在启动器设置里指定路径。

下载的文件名是 client 而不是 client-1.20.1.jar？

跨域下载时浏览器会忽略文件名设置，手动改名即可，但导入启动器只需要 version.json。

模组加载器一直显示加载中？

检查 functions/api/[[path]].js 是否部署成功。浏览器访问 你的域名/api/bmcl/mc/game/version_manifest_v2.json ，能返回内容就正常。

数据来自哪里？

版本元数据与主程序来自 Mojang 官方，下载由 BMCLAPI 加速，模组加载器版本来自 BMCLAPI 镜像。

📚 安装指引

需要下载的文件

在「游戏本体」区块下载两个文件：version.json 与 client.jar。两者必须放在同一个文件夹里，文件名保持默认，不要改名。

HMCL 操作步骤

1. 打开 HMCL，点左侧「版本列表」
2. 点右上角「安装新游戏版本」
3. 切到「从本地安装」标签
4. 选择刚才下载的 version.json
5. HMCL 会自动识别并补全 libraries、assets，等待完成即可启动

PCL2 操作步骤

1. 打开 PCL2，点「下载」→「本地导入」
2. 选择 version.json
3. 等待补全完成，回主页启动

注意事项

首次导入后启动器需要联网补全材质与音效（约 300-500MB），请保持网络畅通。补全完成后即可离线游玩。

Java 版本要求

1.20.5 及以上需要 Java 21；1.17 至 1.20.4 需要 Java 17；1.16.5 及以下需要 Java 8。
